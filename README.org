#+TITLE: scripts

Personal collection of standalone CLI scripts (POSIX =sh= and Perl),
each with a companion man page built from org-mode sources.

* Scripts
- =graba= :: records the current terminal session into a GIF animation
     (X11, and GNOME or wlroots under Wayland).
- =laptop-keyboard= :: enables/disables the laptop keyboard (X11 via
     =xinput=, or Wayland via the kernel sysfs =inhibited= attribute).
- =psh= :: a simple interactive Perl shell (REPL).
- =set-gdm-avatar= :: sets the user avatar (~/.face) as the GDM login
     screen icon via AccountsService.
- =set-static-ipv4= :: assigns a static IPv4 to WiFi connections
     matched by name pattern.

See the man page of each script (e.g. =man set-gdm-avatar=) for full
usage, options, and dependencies.

* Building
The scripts are distributed as a Debian package.  The scripts install
under =/usr/local/bin/= and the man pages under
=/usr/local/share/man/= (see [[https://man7.org/linux/man-pages/man5/manpath.5.html][manpath(5)]] for details on how man finds
them).

A =Makefile= drives the common tasks:

#+begin_src shell
  make         # build the .deb package (default target)
  make deb     # same as above
  make man     # regenerate man pages from doc/*.org for review
  make test    # run the test suite (no install or root needed)
  make clean   # remove build artifacts (build/, man/, *.deb)
#+end_src

=make deb= runs =build-deb.sh=, which regenerates the man pages from
=doc/*.org= via =tools/build-man.el=, so =emacs= must be on =PATH= at
build time.  The resulting =scripts_1.0_all.deb= is left in the repo
root.

If you prefer not to use =make=, the underlying commands are =sh
build-deb.sh= (build) and =sh test/run.sh= (test).

* Testing
The suite runs the scripts straight from =src/= with no install, root,
display, or hardware required.  It uses TAP with =prove= and mocks every
external tool.

#+begin_src shell
  make test                # or: sh test/run.sh
  make test TESTARGS=-v    # verbose TAP output (or: sh test/run.sh -v)
#+end_src

Note: =make test -v= does not work --- =make= treats =-v= as its own
=--version= flag.  Use =TESTARGS=-v= to pass flags through to the
runner, or invoke =sh test/run.sh -v= directly.

* Installation
Install the built package with:

#+begin_src shell
  sudo dpkg -i scripts_1.0_all.deb
#+end_src

or with =apt=, which resolves the runtime dependencies:

#+begin_src shell
  sudo apt install ./scripts_1.0_all.deb
#+end_src

To remove the package:

#+begin_src shell
  sudo dpkg -r scripts
#+end_src
